# compare_DATA Directory Description

This directory stores all experiment-related **training logs, training metric CSVs, and ablation inference results** for paper analysis and comparison.

---

## Directory Structure Overview

```
compare_DATA/
├── train_record/                  # Training process records (logs + CSV metrics)
│   ├── phase1.log                 # Phase 1 full training log
│   ├── phase1.csv                 # Phase 1 training metrics (full 20 epochs)
│   ├── phase2-wsm0.005.log        # Phase 2 training log (WSM=0.005, LPIPS=0.1)
│   ├── phase2-wsm0.005.csv        # Phase 2 training metrics (WSM=0.005, LPIPS=0.1)
│   ├── phase2-wsm0.0.log          # Phase 2 training log (WSM=0.0, LPIPS=0.1)
│   ├── phase2-wsm0.0.csv          # Phase 2 training metrics (WSM=0.0, LPIPS=0.1)
│   ├── phase2-lpips0.0.log        # Phase 2 training log (WSM=0.0, LPIPS=0.0)
│   └── phase2-lpips0.0.csv        # Phase 2 training metrics (WSM=0.0, LPIPS=0.0)
├── wsm0.0/                        # WSM=0.0 (weight smoothing regularization off) ablation inference results
│   ├── ckpt_phase2_best.csv       # Full model (learned fusion + delta + struct + gate)
│   ├── ckpt_phase2_best_ng.csv    # Ablation: no blurry region gate (no gate)
│   ├── ckpt_phase2_best_nod.csv   # Ablation: no delta correction (no delta)
│   ├── ckpt_phase2_best_ns.csv    # Ablation: no StructureEncoder (no struct)
│   ├── ckpt_phase2_best_t-linear.csv # Fixed fusion strategy: t-linear weights
│   └── ckpt_phase2_best_uniform.csv  # Fixed fusion strategy: uniform weights
├── wsm0.005/                      # WSM=0.005 (full model with weight smoothing regularization) ablation inference results
│   ├── ckpt_phase2_best.csv       # (same 6 files as above, same config, different checkpoint only)
│   ├── ckpt_phase2_best_ng.csv
│   ├── ckpt_phase2_best_nod.csv
│   ├── ckpt_phase2_best_ns.csv
│   ├── ckpt_phase2_best_t-linear.csv
│   └── ckpt_phase2_best_uniform.csv
├── metrics_all_server.csv         # Full validation set (30 sequences, K=9, 2640 frames) baseline method comparison
├── metrics_kf3_server.csv         # K=3 validation set (30 sequences, 1980 frames) baseline method comparison
├── ablation_avg_compare.csv       # Ablation AVG summary CSV (auto-generated by gen_avg_compare.py)
└── gen_avg_compare.py             # Script to extract AVG rows from wsm0.0/ and wsm0.005/ and summarize
